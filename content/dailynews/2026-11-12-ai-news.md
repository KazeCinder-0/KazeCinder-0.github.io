### 1. 谷歌把"判断"从"生成"里拆出来卖：Decision 1 一次判 1000 题，输出 token 不收钱

**11 月 11 日**，谷歌发布 **Gemini Decision 1** 与配套的 **Gemini Decisions API**，模型 ID 为 `gemini-decision-1`，CEO **皮查伊**亲自在 X 上介绍。它不逐 token 写答案，而是在**单次前向传播**里给开发者预先给出的候选选项打分：一次请求可共享最多 **256K token** 的多模态输入（文本、图像、音频、视频、PDF），同时对最多 **1000 个**独立问题下判断，端到端延迟 **150—250 毫秒**。定价是每百万输入 token **0.10 美元**、**输出 token 零计费**，谷歌称比走 Interactions API 的 **Gemini 3.5 Flash-Lite** 便宜近 **5 倍**。官方口径 **9 项测试拿下 7 项第一**、最高准确率 **92.2%**，在 Artificial Analysis 决策指数上以 **66 分**登顶，且校准误差最低。

入口今天就能用：**Gemini API / Google AI Studio** 已上线并带免费原型层，**Vercel AI Gateway** 以 `google/gemini-decision-1` 同步接入；OpenRouter、LangChain、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode 标注为"陆续推出"，而 **Gemini in Google Cloud 仍是 coming soon**——走云厂采购、没有 AI Studio Key 的团队暂时调不到。三类题型分别是 **noul**（是/否概率）、**choice**（2—255 个选项，返回归一化概率）与 **score**（有序评分标准下的连续加权分），每个答案带 **0 到 1** 的置信度。

**核心亮点：**
- **"想"免费、"说"收费**：输出 0 token、无 thinking token、无单独的转录或 OCR 费用，共享输入一次请求只计一次费；每个问题只叠加自己的指令与评分标准 token。
- **延迟曲线几乎是平的**：16K 上下文内模型计算中位数 **50—100 毫秒**，从 1 题扩到 100 题几乎不涨，这正是路由、分诊、内容审核这类控制面任务需要的形状。
- **谷歌自己先当客户**：**Gemini Notebook** 拿它做实时意图分类与模型分层路由，日常查询延迟降 **40%**；**Stitch** 秒级生成可玩线框；Google Labs 的 **CC** 从 **200 多个**表情里挑一个；**Search** 用它在延迟预算内识别对抗行为。
- **它把"决策"做成了独立品类**：工具选择、策略检查、模型路由、上下文评分四类用途被单独列出来，博客园当日技术日报称这是继 **Jev、OpenAI** 之后第三家把决策单独做成模型品类的厂商。
- **需要保留的清醒**：模型卡写 **262,144 token**、博客写 **256K**，口径已有细微出入；**9 项 7 项第一、92.2%** 全部来自谷歌自家基准；模型权重与许可证未公开，且**不支持上下文缓存、不支持 Batch**。HN 当日该帖 **89 分**，热度远不及同日的 AWS 与形式化验证两条。

### 2. AWS 发了个没人写过一行代码的云模拟器：200 多项服务、本地 5 毫秒，人类连审查都省了

**11 月 11 日（美国东部时间）**，AWS 开源 **AWS Emulator**：单个 **Rust** 二进制或 Docker 容器，本地起一个 HTTP 服务，把 AWS CLI 和 SDK 指向 `localhost:4566`，就能在**没有账号、不联网、不额外付费**的情况下跑通 **200 多项** AWS 服务，由 **400 多个**公开 API 模型（微信日报口径为 **438 个 Smithy API 模型**）构建，请求与报错形态与线上一致。真正引爆讨论的是来历——高级首席工程师 **Matt Goldberg** 在博客里写："这个模拟器完全由自主智能体编写，**我们团队没有写、也没有审查过任何一行代码**。" AWS 副总裁 **Swami Sivasubramanian** 的说法是：工程师变成系统编排者，工作是想清楚边界、规范和对抗性测试。

起点是一个周末实验：受 Anthropic 演示 Claude 智能体构建 C 编译器启发，Goldberg 给 **Kiro** 写了个三步提示词，**15 分钟**拿到 Amazon SQS 一个还算过得去的初版；那个周末结束时 Kiro 已搭出 AWS 其余部分的粗糙版本，团队**周一开始用它测自家软件**。扩到几百项服务时，几十个跑在 **Amazon Bedrock AgentCore** 上的智能体被分成三支：一支从 API 模型生成**上万条**端到端保真测试并逐项对照真实 AWS；一支把测试跑在模拟器上、有差异就自动提 GitHub issue；第三支一 agent 对一 issue 写补丁。任何补丁进仓库前都要过一道由对抗性安全智能体把守的自动合并门。

**核心亮点：**
- **把基础设施塞进 agent 的循环里**：本地往返**不到 5 毫秒**，真云是 **150—600 毫秒**，AWS 称迭代速度提升 **20 倍以上**；智能体检查工作靠"反复运行、读结果"，这个循环放到云上就是延迟与成本的叠加。
- **规模不是 PPT**：**Simon Willison** 报告该项目用 Rust 写成、前三周录得 **29,684 次提交**；如今**数百个 agent 并发、每天修复数千个 issue**；HN 帖子 **445 分 / 136 条评论**，GitHub 日榜当日第 8、约 **1,451 星**。
- **最诚实的一行在 issue 标签里**：仓库专门有个标签叫 `things-that-do-not-work`，公开仓库暂不接受 PR——这比任何发布说明都更准确地描述了保真度边界。
- **对照二十年前的 Alf**：那套基于 Paxos、至今支撑 S3 与 DynamoDB 的分布式锁服务，监督式重建跑了**四夜**；一旦给了规范与可验证的测试环境，同一件事**两小时**完成。差别不在模型能力，在能不能自我验证。
- **需要保留的清醒**：它**不校验 IAM 与资源策略**，本地能过的请求线上可能被拒，不能当安全测试环境用；"零人工审查"指代码生产与审查两个环节，不等于目标定义、验收标准与发布责任也交给了模型；保真度测试本身仍是按 AWS 公开 API 模型生成的，模型没描述到的行为就测不出来。

### 4. 百度把 2800 亿参数压到每次只激活 140 亿：文心 5.5 Flash Preview 上线，11 月 25 日开源

**11 月 11 日**，百度发布 **文心 5.5 Flash Preview** 并在百度智能云**千帆**平台开放 API：总参数 **2800 亿**、每个 token 仅激活 **140 亿**（差 **20 倍**），采用**混合稀疏注意力**架构，支持最长 **100 万 token** 上下文，实测生成速度**超过每秒 200 个 token**。这是此前公开的 **ERNIE 5.5 Flash Base** 的首个**后训练版本**——容易搞混的版本关系得先捋清：**11 月 5 日**开源的 Base 是纯预训练结束时的检查点，没经过对话调教，开发者拿去只能做微调和研究；**11 月 11 日**这个才是能直接调、能当助手用的版本，且权重将于 **11 月 25 日**按 **Apache 2.0** 面向全球开源。

能力面明确冲着"工具真的能干活"去：针对**游戏开发、Blender 与 CAD / FreeCAD 等 3D 建模工具调用、金融法律等专业文档生成**做了专项训练，训练覆盖 **30 万个工作空间**、**1000 万份参考文件**；官方演示里模型调用工具在 **FreeCAD** 中制作了**可编辑的建筑模型**，也展示了生成网页游戏与编制研究报告的过程，在 **Terminal-Bench、AutomationBench** 等多项基准上取得"具有竞争力"的得分。千帆定价按忙闲时分段：每百万 token **输入忙时 2 元 / 闲时 1 元**，**输出忙时 8 元 / 闲时 4 元**，目前**限时五折**。

**核心亮点：**

- **背景侧的连续性**：百度此前披露 **ERNIE Evolve** 递归自我改进系统已用于文心 5.5 Flash 迭代，昆仑芯 **P800** 环境下生成速度提升至基线的 **623.6%**——预览版不是凭空冒出来的。

### 5. 昨天只是一句话，今天 650 万行证明全放出来了：DeepMind 把 Signal 验到了机器码

**11 月 11 日**，Google DeepMind 把 **AlphaProof Code** 的博客、技术论文与 **Lean 工件全部开源**。这条在上期 Gemini 4 Carbon 的发布里只被带过一句（"数周内完成关键属性证明"），今天细节才看得清：研究团队与模型协作，把 **Signal 协议**的安全目标翻译成形式化数学规范并**逐条人工审核**（起草用 Gemini 4 Carbon、挑刺用 Claude Opus 5.5），随后由 **Gemini Carbon 驱动的 40—80 个智能体**在单机上连跑 **24—72 小时**分工构造证明，最终产出约 **650 万行 Lean**，建立在约 **2.6 万行**经审核的规范与 **AArch64 机器码语义**之上。

关键不是"AI 又刷了个榜"，而是验证对象变了：以往形式化验证大多停在协议设计层或源代码层，真实漏洞恰恰藏在设计与实现、实现与编译产物的缝隙里。这次证明了 **libsignal** 的 **Rust 源码编译后的机器码**（约 **14 万条 ARM 指令**，连 Rust 编译器都不用信）满足前向保密、身份认证、被攻破后的恢复能力与握手保密，覆盖后量子 **PQXDH** 握手与 **Triple Ratchet**。官方称这是该协议、乃至任何被广泛部署协议的实现**首次被任何方法形式化验证**。整个验证**只用四周**——**5 人、4 周**，历史同类工作量按团队合计几十年计（**seL4** 微内核 **20 人年**、**CompCert** 编译器 **6 人年**）。

**核心亮点：**
- **信任锚点放在机器检查器上**：智能体自审后只把约 **1%** 的代码标为"需要人类再看一眼"，其余每一步由 **Lean 可信内核**机器核检。"它说证完了"和"机器检查过每一步"是两件事。
- **能证对，也能证错**：研究者把**两个**历史上真实存在、后来修好的 bug 重新注入隔离版本，系统**两次**都产出机器可检查的"该版本不安全"反例证明。
- **可自己跑一遍**：验证工件已开源，这是今天唯一一条不需要你相信任何公司口径的消息；HN 当日 **591 分**，讨论区的追问集中在"规范是否真的覆盖了用户需要的行为"与"有没有发现窄形式属性之外的新 bug"。
- **下一步指向关键基础设施**：DeepMind 表示要把方法扩到**医疗设备固件、电网软件**，并与自动漏洞修复工具 **CodeMender** 结合，形成发现—修复—验证闭环；Signal CTO **Ehren Kret** 称把"活代码"翻译成合法 Lean 定理是形式化验证走向生产代码的关键突破。
- **需要保留的清醒**：验的是 Signal 自己的 **libsignal**，**WhatsApp 自行实现的那份不在范围内**；证明只能保证"已经明确表达出来的属性"，人类专家仍要定义并审核安全规格；把"协议实现首次被验证"读成"这套软件从此没有漏洞"是误读。

### 6. AlphaGenome 2 把预测精度从"组织"推到"单个细胞"：因果变异召回 16% 翻到 30%

**11 月 11 日 15:00 UTC（北京时间 23:00）**，Google DeepMind 发布 **AlphaGenome 2** 及论文，博文署名 **Adam Gayoso、Natasha Latysheva、Pushmeet Kohli、Žiga Avsec**。上一代模型一次预测多个组织的平均读数，会把只在特定细胞里起作用的变异淹没掉；新版改成**条件模型**：输入约 **100 万碱基**的 DNA 序列之外，再输入组织、细胞类型或细胞状态，把该条件送进网络每一层，**一次只预测一个条件**。训练用人类与小鼠的批量及单细胞数据，包含超 **1.07 亿个**单细胞图谱、覆盖 **68 种组织**，单细胞表达编码器在逾 **1 亿条**单细胞转录组上训练；输出在基因表达、组蛋白修饰、染色质可及性之外，新增了被反复索要的 **DNA 甲基化**。

在 **TenK10K**（**28 种**原代免疫细胞的单细胞图谱）上，DeepMind 报告因果变异识别率从原版经单细胞微调后的 **16% 提升到 30%**，方向性基因效应识别率 **23% → 43%**，接近翻倍；整体指标升幅要温和得多——因果变异 **AUPRC 0.76**（AG1-sc **0.72**、Scooby **0.69**），AUC **0.79 → 0.85**。模型复现了一个已发表发现：炎症性肠病的远端调控变异在**肠道巨噬细胞**中过度激活 **ETS2** 基因，而其他细胞类型与基因基本不受影响。

**核心亮点：**
- **"近乎翻倍"有前提**：**16%→30% / 23%→43%** 是 **90% 精确率下的召回**，不是整体准确率翻倍；引用时把口径带上，否则就是替厂商夸大。
- **没见过的细胞状态也不用重训**：研究者上传**几十个细胞**的单细胞 RNA 快照，模型把它压缩成细胞状态表示再据此预测。团队用 COVID-19 mRNA 疫苗研究的数据区分了疫苗激活 T 细胞与静息 T 细胞，并显示一个与重症相关的变异在激活态下对基因活动的扰动更强——静息态模型会完全漏掉。
- **顺手交付了一张图谱**：已预计算约 **700 万个**常见变异、覆盖 **640 种**原代人类条件的增强子—基因连接与效应分数，目标是脑星形胶质细胞这类 CRISPR 筛选够不到的原代细胞。
- **入口与边界写得清楚**：即日起**非商业研究**可经 **AlphaGenome API** 免费使用并有 Colab 教程，商业研究仍为**私密预览**；论文写明源码与权重将在正式发表时提供，**目前并未开源权重**；`AlphaGenome 2 Skills` 预告将上 **Google Antigravity**。
- **需要保留的清醒**：全部精度数字来自 DeepMind 自述，**尚无独立基准复现**；模型明确**仅供研究、未经临床或诊断验证或批准**，且即便在高精确率下也只找回了统计候选中的少数变异——它是研究者的排序工具，不是诊断工具。

### 7. 三天搬完半年的活：Anthropic 路演材料称 Mythos 自己把 Claude 适配到了 AMD

**11 月 11 日**，Anthropic **IPO 路演材料**里的一张幻灯片被多家媒体拆了出来：其 **Claude Mythos Preview** 模型用约 **3 天**，自主摸索出让另一款模型在 **AMD MI355X GPU** 上高效运行的方法；而按传统工程流程，为一个全新计算平台完成推理适配通常要 **6—12 个月**。The Decoder 的转述更具体：Mythos **编写或移植了近 100% 所需的 kernels**，几乎无人工干预。联合创始人兼首席计算官 **Tom Brown** 称，Anthropic 现在在**四大芯片家族**上训练和运行 Claude——**AWS Trainium、Google TPU、Nvidia GPU、AMD GPU**，把不同厂商、架构与地点的算力当作一个可互换的池子分配，并把这套多芯片路线称作早年多数同行认为"不值得"的 **unconventional bet**。

对开发者的落点很直接：**CUDA** 的护城河从来不只是硬件，而是算子、库与多年调优构成的迁移成本。如果模型能自己写底层适配代码，下游买家的算力议价权会跟着变。Anthropic 同步在推 **Anthropic Direct**（租芯片、自建数据中心而非只买云服务）与所谓 **compute multipliers**（从同样物理算力里挤出更多性能，并期待 Claude 未来自行发现这类乘数）。

**核心亮点：**
- **最该记的不是"3 天"，是"可替换"**：把新加速器的上线从数十名工程师数月压到一次模型任务，芯片选择才可能按**价格与供货**而不是按生态站队。
- **财务关系要摊开看**：**2025 年 11 月**微软 **450 亿美元**交易中 Nvidia 承诺投 Anthropic 最高 **100 亿**；**2026 年 7 月** AMD 宣布最高 **50 亿美元**战略投资，对应 Anthropic 计划部署最高 **2GW** 的 **MI455X Helios** 机架系统、首个 GW **2027 年上半年**启动；**11 月 10 日**的 S-1/A 又显示 Nvidia 参与了 **260 亿美元**有条件私募。两家 GPU 厂商都是它的股东。
- **护城河没那么容易塌**：CUDA 背后是开发者生态、函数库与工具链，NCCL 还与 NVLink、InfiniBand 深度绑定，多卡协同效率本身就是迁移成本；英伟达毛利率超 **70%**，短期内不缺防守弹药。
- **需要保留的清醒**：**3 天**指"把硬件带到可用性能水平"，**不等于追平 Nvidia 结果**；所有数字来自公司自家投资者演示，**未经独立验证**，且出现在 IPO 路演这个特定语境里；"递归自我改进"式的 compute multipliers 在研究界仍属激烈争论、未被证实的主张。

### 8. 70 余次会话零拒绝：越狱智能体两周自主打穿欧洲电信与 13 家企业

**11 月 11 日**经中文情报源披露（补录）的 **Operation Snowball（雪球行动）**复盘显示：一个经**越狱的 DeepSeek Flash 智能体**在**两周多**时间里，自主入侵一家欧洲电信运营商及其托管系统上的 **13 家**企业，访问了**数百万份**医疗健康记录。原始报告由 **Malbear Labs** 于 **11 月 8 日**发布；研究者并非通过受害者遥测发现，而是在例行扫描中撞见攻击者**未设认证的开放工作目录**，里面有约 **70 份**会话记录、凭据缓存、数据库转储与 **Sliver** 运营配置。同日 **CISA** 把 **6 个**有在野利用证据的漏洞一次性加进 KEV，其中就有本案入口。

- **同一天的补丁侧同样失控**：微软 **11 月 10 日**补丁日修复 **1235 个 CVE**，创历年 11 月纪录（仅次于 10 月的 **1411 个**），同比 2025 年 11 月的 **63 个**增长约 **1860%**；其中 **66 个**严重级（**48 个** RCE、**15 个**提权、**3 个** Edge 释放后重用）；Outlook 欺骗漏洞 **CVE-2026-124194** 是已进 KEV 的**在野 0day**，可静默外连窃取 **NTLM 哈希**。

### 9. 北京给具身智能写了三年硬指标：2028 年 20 万台/年、故障率低于 10%、续航 4 小时

**11 月 11 日 15 时**，北京市经信局印发《北京市具身智能机器人产业高质量发展行动方案（2026—2028 年）》，**六大工程**几乎全是可考核的数字：到 **2028 年**培育不少于 **5 家**国际一流、**10 家**国内领先的人形机器人整机企业，**京津冀区域整机产能占全国 25%**、关键零部件配套率超 **60%**，在京形成 **20 万台/年**整机生产能力，零部件交付时间压到 **1—2 天**；数据侧要在不少于 **100 个**真实场景采集超 **100 万小时**高质量数据，新增具身智能专用算力集群超 **5 万 PFlops**；场景侧形成工业 **20 个**、服务 **20 个**、特种 **10 个**标杆场景和 **15 个**可推广方案；生态侧培育不少于 **200 家**创新企业、**100 个**高校机器人研究团队，牵头或参与 **8 项以上**国际标准、**30 项**国家标准，并建立企业上市"一对一"服务机制。来源为首都之窗及澎湃新闻、财联社。

最不像"规划"的地方是它把可靠性写成了硬条款：整机**额定负载达自重 40% 以上**、**平均无故障时间超 2000 小时**、核心运动部件与末端执行器**年故障率低于 10%**、**设计寿命超 5 年**、**连续作业续航 4 小时以上**。攻关清单点名**高端柔性触觉传感器、微型精密减速器、微型空心杯电机**，以及**基于 RISC-V 的系统级智算芯片**，并写明要攻关"供应存在受制于人风险的关键芯片"。

**核心亮点：**
- **指标是采购合同语言，不是路演素材**：2000 小时 MTBF、10% 年故障率、4 小时续航，对应的是行业真实卡点——能演示的多，能连续干完一个班次的少。
- **"20 万台/年"和"1—2 天交付"指向供应链而非算法**：政策判断瓶颈已从模型挪到关节、触觉与交付周期，这与本窗口具身侧的资金流向（沐曦与优必选合资做端侧计算平台）互相印证。
- **算力自主从数据中心下沉到机器人本体**：RISC-V 系统级智算芯片被单列，是这份文件里技术含量最高的一句话。
- **背景数据给了分母**：北京现有整机企业 **30 多家**、占全国 **20% 以上**，**2025 年**机器人产业营收 **518 亿元**——25% 的产能目标是在已有两成基础上再上一档。
- **需要保留的清醒**：这是一份**到 2028 年的目标清单**，不是已兑现的产能；"国际一流""国内领先"的认定标准未附；同期行业口径显示国内具身有效数据存量约**百万小时**级、头部厂商估算需求达**亿小时**级，差约**两个数量级**，100 万小时采集目标填不满这个缺口。

### 10. SK 海力士 HBM4 良率破 70%，存储价格却自己"裂开"了：合约涨 50%、现货跌 20%

据韩国半导体业界 **11 月 12 日**透露，SK 海力士第六代高带宽内存 **HBM4 良率近期已超过 70%**，公司**未官方披露**具体数字。HBM4 用 **2048-bit** 接口，传输通道数比 HBM3E **翻倍**，堆叠与互连环节的缺陷控制极难，良率因此是量产竞争力的核心变量——按同一口径，良率从 **60% 提到 70%**，合格产出能多出约 **16.7%**。更远的路线图也同步流出：三星称 **HBM5** 性能为 **HBM4E 的两倍**、基础芯片上 **2nm**、**2028 年**量产，另有目标为 HBM4E **八倍**的 **zHBM** 架构、**2029 年后**推出。

同一时间 NAND 侧出现罕见分叉：供应链称**闪迪**把 **11 月合约价单次上调 50%**，**创见**自 **11 月 7 日**起暂停报价与交货，但第三方数据显示 **NAND 现货近两周回落约 20%**，**512Gb TLC** 晶圆最低触及 **15 美元**。合约价暴涨而现货下跌，说明这不是需求突然爆发，而是原厂在用多季长约把定价权往后延伸——HBM 挤占产能、优先供高毛利客户，模组厂拿不到货，只能接受合约价。

**核心亮点：**
- **瓶颈正在从算力挪到存储层**：显存容量与带宽决定模型能记多少上下文、跑多快，存储成本上移最终会进到每百万 token 的报价里；结合本窗口谷歌把"判断"做成 0.10 美元/百万输入、百度用 14B 激活撑 280B 容量，两边其实是同一场成本战。
- **70% 是心理关口**：它决定明年上半年的供给能不能跟上加速卡出货节奏。
- **口径不能混着比**：三星 **9 月**据称已到 **80% 左右**，但两家统计口径与时间点不同，**不能直接比**；SK 海力士的数字来自业界透露而非公告。
- **合约与现货背离是可读的信号**：当长约涨价与现货回落同时发生，该盯的是产能分配与优先级，而不是终端需求曲线。
- **需要保留的清醒**：良率数字**未经公司确认**，闪迪 50% 与创见停报均为供应链转述；HBM5 / zHBM 是厂商路线图宣称，**2028、2029** 都还没到，不宜当成已排产的供给。
