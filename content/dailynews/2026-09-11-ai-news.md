# AI 速递 | 2026-09-11

> **信息窗口**：2026-09-10 09:00 — 2026-09-11 09:00（北京时间）
> 今日关键词：**OpenAI Agents API** · **DeepSeek V4.1 Flash** · **Windows 版 Gemini** · **Claude for Microsoft 365** · **国产算力** · **AI 财报季**

## 🚀 今日热点

### 1. OpenAI 推出 Agents API 公测版，把行业推入「Agent Runtime」竞争时代

OpenAI 将驱动 Codex 与 ChatGPT for Work 的底层编排（harness）+ 沙箱打包成**免费云托管服务**对外开放。一次 API 调用即可创建生产级 Agent，核心能力包括：长会话上下文自动压缩、按需加载工具定义（tool search）、多代理并行协同。官方同时开源了 Codex harness，并接入 9 家沙箱合作伙伴（Modal、Cloudflare、E2B、Vercel、Oracle、DigitalOcean 等）。

**核心亮点：**
- harness 随模型版本迭代「赠送」，第三方编排框架（LangGraph/CrewAI/AutoGen）护城河被大幅压缩
- 定价锚点定死：harness 免费，只收 token + 工具调用费，直接冲击国内靠编排层收费的 MaaS 平台
- 客户案例硬指标：SafetyKit 单案例成本降 60%、Hypha 失败响应降 86%、Ciridae 延迟降 4 倍

---

### 2. DeepSeek 正式发布 V4.1 Flash：原生视觉 + 非对称新架构 + 价格重排

DeepSeek 于北京时间 9 月 10 日 12:00 正式发布原生支持视觉理解的 **V4.1 Flash**（API 名 `deepseek-flash`）。采用非对称 Causal-Encoder-Decoder 架构，输入/输出分别激活 8B / 16B 参数；官方称相较上一代，缓存对 HBM 与 SSD 的需求分别降至 1/4、1/8。保留峰谷定价，并计划自 9 月 14 日 12:00 起将 `deepseek-v4-pro` 请求路由到 V4.1 Flash 计费。

**核心亮点：**
- 首次把视觉理解做成原生能力，告别此前「插件式」多模态
- 缓存成本骤降，直接拉低长上下文推理的单位成本
- 9 月 14 日接口切换节点值得开发者关注（V4 Pro 流量将自动转 V4.1 Flash）

---

### 3. OpenAI 上线 Data 插件与文件库连接：一句话把企业数据变成看板

ChatGPT Work 与 Codex 新增 **Data 插件**，可分析已连接的业务数据、探查指标变化并生成交互看板/报告，沿用连接账户的既有权限。同日 ChatGPT 文件库接入 **Box、Dropbox、SharePoint**，支持浏览搜索文件、按文件夹选取材料并在对话旁预览、回链原始来源。

**核心亮点：**
- 企业数据无需导出即可在对话内分析，权限沿用现有工作区控制
- 文件连接先推网页端，移动端随后；与 OneGov 政府方案形成「数据 + 权限 + 采购」组合拳

### 4. OpenAI 新一轮 OneGov 协议：美国政府机构免许可费、用量五折

OpenAI 与美国总务管理局（GSA）宣布新的多年期 OneGov 协议，并将同款优惠扩展至符合资格的联邦、州、地方及部落政府：免去标准每用户每月 15 美元许可费，用量费用打五折，不设最低用量承诺。9 月 14 日说明会将介绍适用范围与上线安排。

**核心亮点：**
- 这是 OpenAI 把「政府采购门槛」摆到前台的关键动作
- 与 Data 插件、文件库连接一起，指向「具体工作流收尾能力」的竞争

### 5. Google DeepMind：Windows 版 Gemini 上线 + Gemini 3.8 Flash 持续放量

Google 面向全球推出 **Windows 版 Gemini** 应用，覆盖 Windows 10 与 11，Alt+空格 即可在当前界面呼出助手；独立工作区可把多步骤任务交给 Gemini Spark 个人 Agent，并从 Gmail / Drive 提取信息生成项目摘要，桌面端集成 Nano Banana 图像与 Gemini Omni 视频生成。同期 DeepMind 的 Gemini 3.8 Flash 已成为编码与 Agent 主力 workhorse 模型，agentic video understanding 在长视频上可降 token 达 88%、降本 66%。

**核心亮点：**
- 桌面级入口 + 个人 Agent 工作区，对标 Copilot / Claude 的本地化布局
- DeepMind 把「视频理解」从固定抽帧改为 agentic 动态导航，长视频成本显著下降

### 6. Anthropic：Claude 接入 Microsoft 365 + 发布滥用威胁报告

**核心亮点：**
- 办公 Agent 进入「跨应用连续工作流」阶段，可在客户模板内生成可审查的编辑
- 安全披露进入具体流程：厂商识别与封禁 + 欧盟 CRA 24 小时早期预警机制同日适用

### 9. AI 财报季：Oracle 云基础设施收入同比 +121%，Adobe AI-first ARR 超 6.5 亿美元

Oracle（ORCL）2027 财年 Q1：总收入 193 亿美元（同比 +30%），云业务收入 116 亿美元（同比 +62%），其中**云基础设施收入 74 亿美元、同比 +121%**，剩余履约义务（RPO）达 6640 亿美元。Adobe（ADBE）2026 财年 Q3：收入 67.6 亿美元（同比 +13%），AI-first 年化经常性收入（ARR）超过 **6.5 亿美元、同比 +150%**，Firefly 期末 ARR 环比 +40%。

**核心亮点：**
- 模型端在降价，云端仍在高速增长：单次调用变便宜，总用量持续扩大
- 但一份财报不足以证明降价已带来需求爆发，6640 亿 RPO 是待履约合同而非已确认收入

### 10. 安全侧：DeepSeek Harness 沙箱逃逸漏洞 + Cursor 常驻 Agent

DeepSeek 安全研究人员披露 **CVE-2026-82533**（影响 DeepSeek Harness 0.1.1-rc.2 及更早）：本地 API 错误信任客户端可控的 Host 头，沙箱会话仍可访问回环地址，攻击者在默认配置下用一条 Shell 命令即可逃逸沙箱、关闭审批并启用完全访问；0.1.2-alpha.1 已修复。另方面，Cursor 开始测试 **Projects**：把编码协作单位从「逐任务对话」改为单一长期项目线程，由常驻协调 Agent 拆解工作、调度子 Agent，并共享项目记忆与产物。

**核心亮点：**
- 沙箱逃逸提醒：Agent 运行时安全边界是 2026 下半场的核心议题
- Cursor Projects 与 OpenAI Agents API 同向：常驻 Agent + 共享记忆成为编程范式
