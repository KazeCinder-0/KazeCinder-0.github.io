# 朝闻道 | 2026-11-16

## 🚀 今日热点

### 1. 一把只读密钥，串起 Cursor、Uber 与 Notion：Fireworks AI 供应链失守的账单在本窗口集中到期

**11 月 14 日（周五）**，**Cursor** 在一份事故更新里确认：上个月那次"官方 **Claude Code** 扩展被投毒"的根因，是攻击者拿到了 Cursor 发给 AI 推理平台 **Fireworks AI** 的一把访问密钥——"密钥由 Fireworks 泄露，攻击者用它从一个我们用于共享数据的只读存储桶里拷走了数据"。桶里装的是**未开启 Privacy Mode** 的编码智能体会话轨迹，多数可追溯到 **2025 年**，其中混入了**未脱敏的凭据**，影响 **Cursor 不到 0.01% 的客户**。攻击者以此为起点横向进入 Cursor 内部 SaaS，拿到归档的非生产源码仓库、部分客服邮件与对话、产品用量指标、编码会话摘要，以及用户发给客服的凭据；随后在 **10 月 29 日**用偷来的内部凭据，把带毒的 **Claude Code 扩展 2.1.312 / 2.1.313** 直接放进扩展市场的缓存层，**可用约 11 小时、最多 5,000 名用户**可能拉到该构建，恶意代码尝试写入持久化 SSH 后门并回传环境变量名。

同一条链的另一头是普通人。据 **TNW 援引 TechCrunch** 报道，**Uber** 正在通知司机，其个人信息与**驾照影像**从供应商处被盗，供应商被确认为 Fireworks AI。Uber 称 **10 月 9 日**收到通知、**10 月 13 日**调查确认；本周向各州总检察长提交的通知列出**马萨诸塞州 2,567 人、南卡罗来纳州 3,430 人、罗得岛州 1,873 人，合计 7,870 人**，加州与伊利诺伊州居民也收到通知但未列人数，总数可能继续上升。**Notion** 此前确认**不到 1% 工作区**的 AI 聊天记录被暴露。Fireworks 今年 **7 月估值 175 亿美元**，把攻击归咎于倒卖模型访问权限的 **LLMjacking** 团伙，并已关停 Batch Inference 与数据集自助上传下载；Cursor 称 **11 月 1 日**后未再发现恶意活动，已把全部推理流量迁离 Fireworks。

**核心亮点：**
- **"只读"从来不是边界，是权限描述**：一把只为读训练轨迹签发的密钥，靠轨迹里没洗干净的明文凭据，一路跳到内部 SaaS，再跳到开发者机器上的扩展缓存。微信公众号的一篇工程复盘把这条链拆成四步，每一步单独看都是"合法凭证 + 合法路径 + 合法读取"，合规调用不会触发任何告警。
- **平台能吊销自己发的 Key，吊销不了你存进去的第三方 Key**：Fireworks **11 月 9 日**公告原话是"只删掉一个已存储的 secret 并不会让底层凭证失效"——第三方密钥必须逐一回到签发方（云厂商、OpenAI 等）手动轮换。这一句比任何安全白皮书都值得贴到值班手册上。
- **ZDR（零数据留存）覆盖不了"周边任务"**：Uber 为服务商建的专用存储环境里有驾照影像，Notion 把完整对话送去做分类以支持 AI Insights，Cursor 把会话轨迹用于训练。只要涉及批量推理、分类、微调或离线评估，数据就必须落盘，"随用随抛"只是推理接口的默认承诺。
- **今天就能做的四件事**：轮换所有注入过供应商环境的第三方密钥（不是删 Secret）；对共享训练集与对话日志做前置密钥扫描；开启数据面审计（如 S3 Data Events）并用 IAM 条件键把凭证限制在指定 IP/VPC；对扩展市场拉取记录与 SSH 配置变更做一次回溯。复盘还建议以 OIDC 联邦换短期凭证、用 Canary Token 探测滥用。
- **需要保留的清醒**：以上数字来自 **Cursor 周五更新、The Hacker News、TNW/TechCrunch、Uber 州级通知与一篇中文工程复盘**，属多源但**并非全部由 Fireworks 公开确认**——该公司未回答 TechCrunch 的具体提问，也未解释为何司机驾照数据会存放在推理服务商处；7,870 是**三个州的已通报数而非总受影响人数**；5,000 是**可能拉取**而非确认感染。腾讯云、Aviatrix 等第三方综述给出的口径与当事公司公告略有出入，做采购决策应以官方公告为准。

### 2. Claude Code 的 Code Mode 周末走红：让模型写一段 JS 一次跑完工具调用，但"省 37% token"是张冠李戴

**Claude Code v2.1.323** 起加入的实验功能 **Code Mode**，在本窗口成了开发者社区最热的话题。按官方文档，开启后 Claude 不再一次请求一个 **Bash / Read / Edit** 工具、看完结果再决定下一步，而是**直接写一段 JavaScript** 在会话里一次完成多个工具调用：并行跑命令、把上一步结果喂给下一步、只把需要的输出交回模型阅读。文档建议在"工具调用多且相关"的任务上尝试，比如跨很多文件的重复修改、需要先过滤的搜索结果，或几条能同时跑的独立命令。开启方式是在 **v2.1.323 及以上**把环境变量 **`CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`**，功能**默认关闭**，项目自带的配置文件不能替用户打开，企业管理员可统一禁用。

需要把日期讲清楚：这个功能在 **11 月 12—13 日**随版本进入更新日志，**本窗口是周末的集中实测、讨论与一次误传澄清**，不是新发布。流传最广的说法是"Code Mode 能省 **37% token**、让额度多撑很久"，但多名开发者指出，官方 Code Mode 文档**没有给出任何节省比例**，37% 对应的是 Anthropic **2025 年 11 月**关于 API 上 **Programmatic Tool Calling** 的测试（复杂研究任务从 **43,588 降到 27,297 token**）。也有用户自测称节省 **40%–55%** 不等，属个人小样本。开发者 **Rhys Sullivan** 对比了三家实现：Claude Code 在 **Bun** 进程内用 **`node:vm`** 运行，Codex 用 **V8**，OpenCode 用自定义解释器。

**核心亮点：**
- **省的是往返，不是智能**：成本文档里那句关键话是"每次请求都会带上完整对话，每用一次工具就要再发一次请求把工具结果带回去"。Code Mode 把中间的多次往返压进一段本地执行，省的是网络与上下文重放，模型该犯的错一个不少。
- **限制写得比宣传诚实**：目前**只支持终端里的交互式会话**，不支持 `-p`、**Agent SDK**、VS Code 面板、桌面版与云端会话；代码默认运行超过 **10 分钟**会被停止；不能与远程控制、**Claude in Chrome**、电脑操作等功能同时用；Anthropic 强调这是实验功能，可能随时改动或移除。
- **"配置文件不能替你打开"是个好设计**：把实验开关留在环境变量层，意味着仓库里的 `settings.json` 不会悄悄给全队开一个新执行面，企业管理员还能从上层统一封掉。对要过安全评审的团队，这比多一个功能更重要。
- **和本栏前几天写过的两条是同一条线**：上期的 Claude Code Projects 把任务拆给并行线程，Antigravity 让 agent 写 Python 调度 agent，Code Mode 则把工具调用压进一段 JS——三者都在把"编排权"从提示词挪进可执行代码，只是粒度不同。
- **需要保留的清醒**：**37% 是 2025 年另一项 API 功能的测试数字，与 Code Mode 无因果关系**，官方文档与成本页均未承诺任何节省比例；40%–55% 是自测小样本，任务类型差异极大；Node 代码在本地进程内执行，权限边界、`node:vm` 的隔离强度与失败重跑成本都要团队自己评估，"可审查"不等于"安全"。

### 3. 今天早上你的 Copilot 少了三个模型：Claude Opus 4.8、Opus 5、GPT-5.6 Terra 从"所有 Copilot 体验"退役

**11 月 16 日**，**Claude Opus 4.8**、**Claude Opus 5**、**GPT-5.6 Terra** 一起从 GitHub Copilot 退役，范围是官方原文那句"**所有 Copilot 体验**"——Chat、行内编辑、Ask、Agent 模式连代码补全都不留，替换指向 **Claude Opus 5.5**、**GPT-6.1 Sol** 或 **GPT-6 Luna**。该预告早在 **10 月 15 日**的第二波公告里发出、今日生效；按媒体统计，**一个月内九款模型**从 Copilot 模型池下架，**十周之内第四波退役、累计 19 个模型**，且前两波给出的替补如今自己也进了退役名单。最直接的后果：任何在配置里写死 `claude-opus-5` 的流水线，今天第一条任务就可能跑挂。

同一窗口里，治理侧集体收紧。**JetBrains** 把 **Air**（agentic 开发层）内置进 **IntelliJ IDEA 2026.3**，原生支持 **Claude Agent、Codex、Gemini、GitHub Copilot、Junie、OpenCode** 等 ACP 兼容智能体，Copilot 可借用户自有订阅在 Air 本地/云端运行（走 Copilot 额度而非 JetBrains AI 额度），面向组织的 **Air Governance 已 GA**，统一管控团队可用哪些 agent、模型与提供商、支出限额及成效。另有：**GitHub 10 月单周提交超 12 亿次**（同比 **+400% 以上**），而 **Faros AI** 数据显示高 AI 采用团队的 **PR 评审耗时 +441%**；**Claude Code 2.1.325** 让沙箱 Bash 默认需授权；**Google Jules** 已于 **11 月 11 日**转只读、**12 月 31 日**关停；**Copilot model-policy API** 已 GA。

**核心亮点：**
- **这是今天唯一"不做就会出事"的一条**：不是尝新，是排障。个人用户只需重新选模型，企业团队还涉及策略开关、共享提示、自动化脚本、质量基线、费用口径与回归比对——等待系统自动切换，只会让问题集中在同一天爆发。
- **替补也在退役名单上，说明"选一个模型"已经不是一次性决策**：三个月前被通知 A 换 B，这个月又收到 B 也要走。可复用的做法是把模型标识收敛到一处配置或网关，并在 CI 里加一条"模型可用性"冒烟，而不是散落在几十个脚本里。
- **IDE 正在从编辑器变成智能体指挥中心**：JetBrains 走的是中立编排层路线（不绑定单一模型或厂商），并把"谁能用什么 agent、花多少、产出如何"做成组织级产品。竞争维度从"谁家模型更强"转向"谁能把多智能体纳入可管控、可审计的工作流"。
- **生成不再是瓶颈，验证与管控才是**：12 亿次单周提交与 +441% 的评审耗时放在同一张表里，就是这轮治理收紧的全部理由；策略 API、支出限额、模型退役机制集中上线，说明 agent 已被当作"企业生产资产"而非玩具。
- **需要保留的清醒**：退役清单与生效日来自 **GitHub 公告与多家中文资讯站转述**，"一个月九款 / 十周 19 个"是**媒体统计口径**而非官方汇总；JetBrains Air Governance GA 的具体生效时间、Air 与 Copilot 订阅的额度结算细则，官方帮助文档未在本次检索中给出完整说明，涉及采购与合规的团队应自行核对；PR 评审 +441% 来自 Faros AI 单一数据源，样本构成未公开。

### 4. Google /teamwork 把"信任"换成"证伪器"：180 万行 Lean、28,800 次子智能体，以及今天就能用的 /boost

**Google Research** 于 **11 月 13 日**由 **Vahab Mirrokni**（Google Fellow、研究副总裁）发文公布 **Antigravity /teamwork** 多智能体系统的一批成果，本窗口在 **Hacker News 以 192 分、40 条讨论**持续发酵并被多家技术日报收录。设计针对两个弱点：单次生成不可预测，就用并行候选配"**专门的证伪器**"（**Lean 4** 证明检查器、未经修改的测试套件、执行模拟器、Web 搜索、硬件计数器）来判定谁活下来；长任务里模型会丢细节，就按构造切分上下文——每个专家只拿到本步骤需要的文件与工具，协调者把工作交给全新的后继者，批评者与审计者从不带生产者推理过程的干净上下文里复核。工作流写成自然语言模式，由路由器把每条提示分派给合适的一条。

官方给出的数字很大：**Weil 猜想**端到端机器检验的形式化约 **180 万行 Lean**、**28,800 次子智能体调用**（LEAP 框架配 Gemini 4 Argon，全程自主）；**2013 年的 Courtade–Kumar 信息论猜想**在完全一般性下被证明并用 Lean 4 形式化，约 **5,000 万行**（Google、香港中文大学、南加州大学、卡内基梅隆大学合作，人类研究者提供关键归约与下界）；**Zircon 微内核**剩余 C++ 在两周内重写为约 **80 万行 safe Rust**（此前已完成 25% 移植），称通过全部内核单测并在 arm64 上引导；**libgav1** 移植约 **17 万行 Rust**；**30 个专业智能体**结合光谱模拟器做 NMR 分子结构识别，top-1 **95%**、top-3 **100%**；**STOC 2027** 的 578 份自愿投稿中，**14%** 被 Deep Review 发现需一小时以上修复的技术缺口，**90%** 受访者称反馈基本属实；两处已上线的 Borg 调度改动让部分硬件上的 TPU 任务抢占下降 **24%**。

**核心亮点：**
- **最值得抄的不是成果，是那个"不关心模型有多自信"的部件**：Lean 检查器、原始测试套件、硬件计数器都是非模型组件。把"我写完了"改成"检查器说它过了"，是长任务智能体从演示走向可交付的分界线——这也正好接住本栏上期那句"拆分越来越便宜，验收越来越贵"。
- **今天能用的是 /teamwork 与 /boost，不是那两个模式**：Google 说外部开发者现可在 Antigravity 与 Deep Review 里用 Gemini 4 模型配合 **/teamwork**、**/boost**，并开放 **1 万名学术研究者申请六个月最高使用层级免费额度**；形式化证明模式与 Zircon 重写模式明确列为"稍后"。把"已发布成果"误读成"已可复现工具"是这轮报道里最常见的错位。
- **一个反直觉的自查结论值得留意**：/teamwork 复盘过往运行发现，**紧耦合代码用"顺序实现—修订"比并行拆分更好**，Google 把它折进了独立发布的 /boost 编码循环。同一家公司同时给出"并行很猛"和"这里别并行"，比一味堆 agent 数量可信。
- **5,000 万行里只有约 23.9 万行是可读证明代码**：独立核查指出公开仓库约 **45,500 个模块**多为生成的数值证书，由 Lean 内核机械校验，无未完成证明占位、只依赖 Lean 三条标准公理。规模惊人，但"行数"不等于"数学深度"，也不等于人工可审。
- **需要保留的清醒**：**全部结果均为 Google 自述，本窗口未见独立评审或第三方复现**；Weil 形式化的代码尚未公布，而 **Axiom 已于 11 月 6 日**（Google 发文前一周）公布了自己的 Weil 形式化；Courtade–Kumar 的证明预印本（arXiv 2609.24931）早在 **9 月 24 日**列出，11 月新增的是机器验证的形式化与系统总结。另需区分：形式化一个"有限时间爆破"的近期证明，并不等于解决 Navier–Stokes 正则性这个千禧年问题。上期本栏写过的 Antigravity 额度重置与 Dynamic Workflows 属同一产品线，本期是科研成果线，勿混为一次发布。

### 5. Chrome 官方把 DevTools 交给智能体：一批"今天能装"的运行时验证与护栏工具同时上榜

**11 月 15 日 GitHub 日榜**几乎被"给 agent 补上眼睛和刹车"的项目占满。**Chrome DevTools 团队**的 **chrome-devtools-mcp**（TypeScript）单日新增 **664 颗 Star**（另一份日榜快照记为 24h **+752**、总 **56,267**），以 MCP 服务器加 CLI 的形式，让 **Claude、Cursor、Copilot** 等编码智能体直接调用开发者工具能力：检查页面、读控制台日志、分析网络请求。同期 **GoogleChrome/modern-web-guidance-src** 单日 **+1,231 星**居日榜首位，把最新 Web 规范同步为可检索内容以缓解模型知识滞后；**backnotprop/plannotator** **+408 星**，给智能体工作流加规划、批注、代码审查与"把反馈一键发回智能体"的人工审核层；**tradermonty/claude-trading-skills** **+553 星**、**dream-num/univer**（AI 办公 SDK）**+495 星**、**QwenLM/qwen-code**（终端编程智能体）**+64 星**、**腾讯 LoopForge**（Go，脚本编排 CodeBuddy / Codex / Claude Code 并内置人工审批）**+33 星**。

### 7. 159,041 个 Lovable 应用被扫了一遍：护照照片与 20 多万条私信不需要登录就能读

**Crissy Field** 的一份安全研究在 **11 月 14 日**进入 **Hacker News**，到本窗口仍位于首页前列（**972 分、370 条评论**）。研究者扫描了 **159,041 个**用 **Lovable** 构建的公开应用，发现一类反复出现的严重问题：后台数据库直接暴露在公网上，任何人不用登录就能读到用户的**护照照片**与**超过 20 万条私信**。研究页明确说明其分析与数字较 **Handelsblatt 11 月 2 日**的报道已有更新，所以本窗口发酵的是"更新后的完整数据与社区讨论"，而非首次披露。

根因不在模型写错代码，而在**默认值不安全**：新建数据表默认对外开放、**行级权限（RLS）默认关闭**，而"一句话生成 App"平台的用户很多没有工程背景，会把应用直接部署给真实用户。AI Mirror 与盛亚云的复盘都指向同一处——生成式工具不会主动提醒你配置权限，前端做得越漂亮，越容易让人以为后端也已经就绪。

**核心亮点：**
- **这是同一类错误的规模化**：过去一个开发者漏配 RLS 影响一个应用，现在一种集成模式被复制到十几万个应用里。生成式工具把"最佳实践"和"默认失误"一起放大了，且放大倍数是同一个数量级。
- **今天能补的两类检查很具体**：数据库访问策略的静态扫描（RLS 是否开启、anon 角色能读哪些表），以及"**未登录状态下能读到什么**"的自动化探测。后者建议直接做成上线流水线里的一道门禁，而不是靠发布前人工想起来。
- **验收正在变成一门生意**：第三方安全审计、渗透测试、"AI 应用上线前自动体检"会成为新的服务入口；平台侧大概率被迫把数据库权限默认收紧、把安全扫描做成标配。
- **和热点 1 构成一组对照**：Fireworks 是"你把数据交给了供应商"，Lovable 是"你把数据留在了自己没锁的门后"。前者要轮换密钥，后者要改默认值，但共同点都是——数据落盘的地方，比模型本身更值得盘查。
- **需要保留的清醒**：**159,041 是扫描的应用总数，不是确认泄露的应用数**；20 万条私信与护照照片是研究中发现的敏感数据类别与量级，未见逐应用核实清单；HN 分数与评论反映的是讨论热度而非漏洞严重性评级；研究页称数字较 11 月 2 日报道有更新，引用时应以研究页当前版本为准。平台方截至本窗口未见公开回应。

### 10. AI 落到具体的人身上：160 题只错 1 道的税务师"状元"自首，澳洲央行说年轻人先感到压力

据 **IT之家援引韩联社**报道，韩国今年**税务师考试第一名**考生于 **11 月 15 日**向警方自首，承认用**微型摄像头**拍下考题传给生成式 AI，再借智能手机取得答案。他此前就因成绩异常受质疑：第一阶段 **160 道选择题只错 1 道**，四门科目中**三门满分**，**财政学 97.5 分**，税法学概论、会计学概论与商法均为 **100 分**；据报道，他在接受一名律师采访时承认，今年 **4 月和 7 月**的税务师一、二试及**注册会计师一试**中都用了这种方法。韩国总统秘书室长**林光铉**称青瓦台 **15 日下午**召开由政策室长主持的会议商讨应对，因**11 月 19 日高考**在即，有关部门正研究防范办法，案件仍在警方调查中。

同一天，据 **The Decoder** 报道，**澳大利亚储备银行（RBA）**研究人员 **Mike Major** 的一项分析搭建了 AI 就业影响监测体系，发现自 **2022 年底 ChatGPT** 推出以来各类岗位招聘广告都在减少，**AI 暴露度最高的一组降幅最大**；在这一组里 **15–24 岁**劳动者与刚毕业的大学生就业率更低、失业率更高，表现比年长员工更差，软件开发、文职与客服尤其明显。报道提到方向一致的既有研究：**斯坦福大学 2025 年 8 月**基于薪资数据发现 AI 暴露职业中 **22–25 岁**员工就业相对下降 **13%**、年轻软件开发者下降近 **20%**；**Anthropic 2026 年 3 月**研究发现同年龄段求职成功率下降约 **14%**，但整体失业率没有系统性上升。

**核心亮点：**
- **"禁带手机"这条规则已经过期**：隐蔽摄像头加上能看图答题的通用 AI，就足以在专业资格考试里拿第一。防作弊要面对的是可穿戴设备与实时解题的组合，而不是考场门口那个收纳袋。
- **两件事都指向"验收成本转移给了人"**：考试机构要在 19 日前拿出新办法，入门级劳动者要自己证明不是被替代的那一批。技术把门槛削平之后，鉴别与举证的工作落到了最没有议价权的一侧。
- **相关性不等于因果，作者自己先把话说了**：RBA 分析衡量的只是职业在理论上的 AI 暴露度，而非企业实际使用 AI 的情况；疫情后的经济周期与远程办公趋势也可能解释这些数字。招聘平台 **SEEK** 的数据同时显示，AI 在补充现有工作的过程中也带来了对 AI 技能的新需求。
- **对开发者的现实提示是"入门级任务"的定义在变**：如果招聘收缩集中在可由 AI 补全的浅层任务，那么把作品集从"能跑通"挪到"能验收、能审计、能说清边界"，比多刷一个框架更抗周期——这也和本期热点 3、5 的治理主线接得上。
- **需要保留的清醒**：韩国案件**仍在警方调查，处理结果尚未公布**，成绩与科目分数来自媒体报道，作弊链条为当事人自述；RBA 分析为**研究人员个人分析、非央行官方结论**，且明确未证明因果关系；13%、20%、14% 三项数据来自不同国家、不同年份、不同方法的研究，**不可横比或叠加**。
