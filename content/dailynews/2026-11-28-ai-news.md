### 1. 谷歌甩出一根「Gemini 管道」：gemini-api-cli 让 Claude Code 一行命令调全家桶

11 月 27 日，谷歌 Gemini 团队在 GitHub 放出 `google-gemini/gemini-api-cli`，一个 Go 写的单文件命令行工具，Apache 2.0 许可，当天已从 2k Star 涨到 **2.6k**，版本停在 **v0.5.0**，Google AI Studio 产品负责人 Dmitry Lyalin 亲自在 X 上转发。它不做代码 Agent、不读仓库、不改代码，定位是「给宿主 Agent 用的 Gemini API 瘦客户端」——你手头是 Claude Code、Codex、OpenClaw 还是 Hermes，只要能跑 Shell，装一个二进制就能直接调图像生成（`gemini-nano-banana-2.1`）、多人配音 TTS（`gemini-3.8-flash-tts`）、背景音乐（`lyria-3.5`）、视频生成、OCR / PDF / YouTube 解析和音视频转 SRT，媒体命令把文件直接写本地、终端只回一条路径。

真正让 Agent「敢自动调」的是四个为机器设计的细节：`--background` 把耗时调研丢到后台并立刻返回交互 ID，`--usage` 读 KDL 格式完整用法、`--schema` 拿 JSON Schema、`--dry-run` 不联网不读钥匙串先把 HTTP 请求本地验一遍，`--agent-mode` 把报错改成结构化 JSON、stdout 切 TOON 省 token 格式、退出码区分「网络失败 / 参数错误 / 鉴权问题」。安装只要 `curl ... install.sh | bash` 加一个 `GEMINI_API_KEY`，配套的 `gemini-skills` 已有 **4.7k Star**。

**核心亮点：**
- **它拆掉了「想用 Gemini 就得开 Antigravity」的绑定**：旧 gemini-cli 五月被砍换成 Antigravity CLI，工作台壳被骂半年，用户要的其实是接口不是舞台。
- **`--dry-run` 是「能用」和「Agent 敢自动调」的分水岭**：CLI 参数记错、请求体乱拼会让模型幻觉式重试，把命令树打进二进制是从根上治。
- **媒体走本地、路径回传**：宿主 Agent 拿到路径顺手写进代码、塞进 `<img>`、挂到 `<audio>`，全程不切界面。
- **异步体感做对了**：deep research 后台跑、拿 ID 查进度，不是让 Agent 对着转圈两分钟。
- **需要保留的清醒**：走官方 `GEMINI_API_KEY` 按量计费，不能白嫖 Antigravity 会员，重度跑先估预算；项目挂 beta 标签、跟底层 Interactions API 一起演进，升级可能破坏性改动；`CONTRIBUTING.md` 写明只收 Issue 不收外部 PR，想贡献得自己 fork。

### 2. GPT-6 Astra 啃下 4 亿 token 的 83 页量子引力论文：AI 从「总结文献」走到「参与提出框架」

11 月 25 日，斯坦福大学 Leinweber 理论物理研究所的 Venkatesa Chandrasekaran 在 arXiv 挂出一篇 **83 页**论文《An algebraic quantization of gravity from the null cone》（编号 **2611.34924**），提出一套从「光锥 / 因果菱形」出发、在四维洛伦兹时空中做非微扰量子化的方案。论文唯一署名作者是理论物理科班出身的资深学者——伯克利博士、普林斯顿高等研究院经历、2022 年与菲尔兹奖得主 Edward Witten 合写过黑洞熵奠基工作；他同时是 OpenAI 推理团队的物理学家。致谢里写明：多项计算和证明是与 **GPT-6 Astra** 长达数月的反复协作推导，累计消耗约 **4 亿 token**，算力由 OpenAI 提供。论文 11 月 27 日经《商业内幕》报道后在中文社区集中发酵。

技术上，他把时空切成由过去与未来光锥相交围成的「因果菱形」，把引力自由度压缩到光锥边界上量子化，在保留有限引力常数（不做微扰展开）的前提下搭出每一项都绝对收敛的路径积分。论文交出四份验证：引力子两点函数得到含二重对数的**有限闭式解**（传统先展开再求和会重现对数紫外发散）、有限时空区域只有有限维希尔伯特空间且面积算符离散、还原贝肯斯坦-霍金熵并算出史瓦西黑洞一圈对数修正（与 Ashoke Sen 用虚时间路径积分的 13 年前结果一致）、低能极限恢复半经典爱因斯坦方程并在代数层面验证 ER=EPR。

**核心亮点：**
- **任务层级变了**：从「AI 总结已有文献」走向「AI 参与提出理论框架」，人类出物理直觉与路线，模型扛符号推演、不等式放缩、行列式与边界项匹配。
- **「无穷大是展开手法的乌龙」这个结论有算式支撑**：先按牛顿常数展开再对径向模式求和才发散，非微扰算式本身给出有限值。
- **验证链条比标题扎实**：四份验证覆盖微观散射、信息上限、黑洞热力学到宏观经典极限，不是单点秀分。
- **Altman 与 Brockman 公开转发**，OpenAI 把「长程推理 + 科学发现」的模型定位又往前推了一格。
- **需要保留的清醒**：论文 **11 月 25 日**已挂 arXiv、本窗口是中文社区发酵与学界质疑集中期，不算「今日首发」；**未经同行评审**、仅针对**纯真空广义相对论**、未纳入电子夸克等物质场，物理理论的裁判是实验与可推导性，不是文本流畅度或模型名字。

### 3. 腾讯混元 Hy3D 3.6：图片转 3D 按次 3—9 元，200 万面 8K PBR 冲「能进流水线」

11 月 27 日，腾讯混元发布新一代 3D 大模型 **Hy3D 3.6**，面向专业 3D 创作：目标面数上限从 150 万提到 **200 万**，贴图分辨率升到 **8K**，支持水密网格与 PBR 材质输出，可额外导出 STL、USDZ、FBX。作为原生 3D 生成模型，它在训练阶段直接学 3D 资产的几何、纹理与材质分布，更擅长角色、生物、服装和复杂道具；腾讯内部数百名专业 3D 美术与建模师盲测称，其几何整体质量、纹理质量与可用性优于同类模型。模型已上线腾讯云 TokenHub 按次后付费，每次约消耗 **25—75 积分**（1 积分 0.12 元，即约 **3—9 元**），默认并发 3、失败不计费，Miora、游戏资产平台 LAP、影视平台 WorkRally 已接入，混元 3D 系列社区下载量超过 **653 万**。

**核心亮点：**
- **它是「今天就能调」的 API，不是权重**：入口在腾讯云 TokenHub，按次结算，失败不计费，先用几块钱跑一版看方向再决定要不要精修。
- **参数选择瞄准生产管线**：水密网格、PBR 材质、面数上限对普通用户无感，对游戏美术和影视制作却是「能不能用」的硬指标。
- **成本结构变了**：过去外包一个模型几千元，现在先花几元出底稿，竞争重点从「能看」转向「能用进重拓扑、烘焙环节」。
- **653 万社区下载**说明开源策略在积累开发者生态与数据飞轮，与闭源 API 形成两条腿。
- **需要保留的清醒**：盲测来自腾讯内部、非中立第三方基准；这是云端 API 而非开放权重，输出仍是高质量底稿，进商业管线前通常要精修，别读成「建模师不需要了」。

### 4. 英伟达开源 30B「像素即代码」图像模型：用自回归挑战扩散，但只放出了栅格化那一半

11 月 27 日，英伟达在 Hugging Face 放出 **Nemotron-Labs-Image-30B-A3B** 权重：总参数 **300 亿**、每 token 激活约 **30 亿**，基于 Nemotron-Labs-VisualCreation 框架的「Pixel as Code」概念——不把噪声扩散成图像，而是像语言模型预测文本一样预测离散视觉 token。配套的 **6.42 亿**参数分词器把 16×16 图像块量化进含 **196,560** 个 Leech 格点向量的码本；架构从 Nemotron 3 Nano 初始化，混合 Mamba-2 状态空间层与注意力，用 GRPO 做提示对齐。

成绩单有强有弱：长文本渲染 LongTextBench 得 **97.98**（GPT Image 2 为 96.00、Nano Banana Pro 为 97.60），GenEval **92.86**（对比 89.00），但在较新的 GenEval2 上只有 **65.43**，落后 GPT Image 2 的 **81.00**。发布条件也要看清：许可是 **NVIDIA One Way Noncommercial**，仅限研究与评估；验证过的推理示例需要 **4 张 H100 80GB** 加载 32 个 safetensors 分片；能输出可编辑 SVG、HTML/CSS 的 VisionCode 部分仍在「等待法务放行」，这次放出的只是栅格化那一半。

**核心亮点：**
- **一次明确的架构押注**：外观是学到的 token、结构是可输出的程序，用「自回归 + 代码」组合去撞扩散模型。
- **榜单别混着读**：表格标注的是整个 VisualCreation 框架，不能把框架级分数算到这次放出的 checkpoint 头上。
- **同一模型在长文本渲染赢、在新 benchmark 输**，说明评测口径往往决定结论，换个榜就换了个故事。
- **非商用许可 + 四卡 H100 门槛**，对国内从业者更像一份可研究的结构样本，不是能直接拿来干活的模型。
- **需要保留的清醒**：厂商自测、尚无第三方独立复现；VisionCode 的「可编辑程序输出」这个真正差异点还没放，现在下结论为时过早。

### 5. 微信开源 WeMM-Ecom：35B-A3B 电商榜 74.4 分，已在微信电商日均十亿次调用

11 月 27 日下午，腾讯微信视觉团队开源 **WeMM-Ecom** 多模态基础模型家族，包含 **0.8B、2B、4B、9B** 四款稠密模型和 **35B-A3B** 混合专家模型，原生支持「快速直答」与「深度思考」两种模式，开放 BF16、FP8、GPTQ、GGUF 全套权重。在覆盖 **8 大电商场景**的 28 项电商基准与 64 项公开通用基准中，35B-A3B 以 **74.4 分**在电商榜单领先数百 B 参数的旗舰模型，2B 版本在轻量级模型中排名第一。该系列基于 Qwen3.5 与微信自研 WeChat-YATT 训练框架，已在微信电商数百个业务流程落地，日均调用量达 **十亿量级**。

### 6. 给 Gemini 配一套质谱「外挂」：识别准确率从不足 4% 跳到约 97%

11 月 25—26 日，谷歌联合分析化学家推出 **Mass Spec Skills**，面向 Google Antigravity 平台开放，把 Gemini 的化学推理与质谱降噪、分子式打分、碎片标注、结构校验等开源工具及公共化学数据库串成一条工作流。对照实验很直白：在无网络、无技能的条件下，Gemini 3.8 Flash、Gemini 4 Argon、Gemini 4 Carbon 三款模型在 **100 个基准化合物**上的分子识别准确率均**不足 4%**；接入技能后均达到约 **97%**，同时 token 消耗下降——Flash 降近 4 倍、Argon 降一半、Carbon 降近五分之一，轻量模型追平前沿模型。每轮对话可把 **1,761 个原始峰压缩到 19 个可用信号**，并输出化学家可审计的报告。谷歌同时面向 1 万名科研人员开放 6 个月最高档位免费权益。

**核心亮点：**
- **这组对照比领域本身更有启发**：同一个模型换一套工作流，准确率差二十多倍，「AI 答不对」很多时候不是不够聪明，而是没接专业工具。
- **轻量模型追平前沿**：技能包把差距从模型层抹平到工具层，省钱的关键是接对工具而不是换新模型。
- **「输出可审计报告」是好设计**：专业场景里，能被领域专家复核的中间结果和最终答案一样重要。
- **团队规矩可以直接抄**：算账交给表格、查证交给搜索、结论留下证据链，再谈提示词技巧。
- **需要保留的清醒**：这是官方研究博客而非论文、未经同行评审；基准化合物的参考谱图本就在公共库内，对全新分子、对映异构体和高度相近的同分异构体仍无法独立确认结构。

### 7. 日本给高性能 AI 上「安全义务 + 罚则」：草案点名 OpenAI、Anthropic、阿里、DeepSeek

11 月 27 日，日本内阁府 AI 战略专家小组下设的制度研讨工作组召开第四次会议，拿出一份修订《AI 推进法》的草案概要。现行法律 2025 年 5 月通过、9 月全面生效，以政府调查和指导为主、企业配合自愿、无罚金；草案要把「自愿」变成「可执行的义务」。覆盖范围是按在日用户规模等标准判定的高性能 AI 服务商——训练算力等可预先自查是否达标，**OpenAI、Anthropic、Google，以及阿里巴巴、DeepSeek** 都被设想在内；基于开放权重模型搭建的服务也可能按风险等级纳入。

义务分三层：对网络攻击、CBRNE（化生放核爆）滥用和意外行为采取安全措施，包括拒绝回答攻击方法或制造有害物质/爆炸物的问题、防止高概率故障；对网络攻击能力强的系统做**用户身份验证**；发生事故或发现可被利用的缺陷时向政府报告，政府认为报告拿不到必要信息时可现场检查。执法走「建议 → 纠正命令 → 违反命令才处罚」三级阶梯，罚金细节未定，技术开发与使用本身不入处罚范围。技术评估交给日本 AI 安全研究所（AISI），草案提议把这一角色写进所依托的 IPA 法。政府目标是在明年通常国会提交法案，工作组自 10 月 28 日起开过四次会议、11 月 18 日书面发布过第三版概要。

**核心亮点：**
- **非欧盟主要经济体把「带真实制裁的强制安全义务」落地**：从软性推进法转向有罚则的硬规则，是制度设计的方向标。
- **域外效力是关键**：覆盖「在日本有用户的服务商」，直接约束境外前沿模型供应商，不只是日本本土公司。
- **身份验证最值得盯**：用「最强网络能力 AI 不再匿名可用」换安全，隐私派会警惕、安全派会欢迎，怎么定义「网络能力系统」决定网撒多大。
- **开放权重的漏洞还在**：义务绑在「服务商托管的服务」上，下载到本地运行的开放权重模型绕得开，报告里尚未回答。
- **需要保留的清醒**：这只是**草案概要**，罚金未定、详细法案未公开、尚未立法；读卖报道的三项具体义务（身份验证、拒绝攻击类提问、报告安全缺陷）未写入内阁府概要，属媒体口径，不能当成已定条文。

### 8. OpenAI 反诉苹果：12 项诉由打到供应链，AI 硬件之争从产品走向人事与合同

11 月 27 日，OpenAI 连同其收购 Jony Ive 的 io Products 单元、两名前苹果员工 Chang Liu 与 Tang Yew Tan，在加州北区联邦法院对苹果提交答辩与反诉（案号 **5:26-cv-07078**，Doc. 217），共列 **12 项诉由**，主张苹果违反联邦《保护商业秘密法》、故意干扰现有供应商合同、违反加州不正当竞争法。OpenAI 称，一名被称作「Employee X」的前苹果员工 2025 年 12 月加入 OpenAI，在约六个月里反复把未发布的硬件设计与制造文件发到个人账户（含个人手机号），2026 年 6 月 2 日离职返回苹果，并带走数十份机密文件、向苹果高层汇报这些内容和 OpenAI 未发布产品路线图。反诉状还指苹果让员工用个人 iCloud 和 iMessage 处理工作文件，等于给离职者设下「随时可触发的陷阱」，并称已有约 **400 名**苹果员工转投 OpenAI、苹果向共同供应商施压要求暂缓支持 OpenAI。

争端始于苹果 7 月 10 日起诉 OpenAI 与两名前员工盗用商业机密用于自研消费硬件。苹果回应称反诉是「转移视线的透明伎俩」，法院已命令 OpenAI 停止使用苹果机密信息；原始审判定于 **2027 年 7 月 19 日**。

**核心亮点：**
- **竞争维度升到供应链与人事**：争的不是某个功能，而是「谁来控制可能不依赖传统 App 和操作系统的下一代 AI 设备」。
- **「离职陷阱」是新的法律叙事**：把用工协议和个人云盘做法直接定义为设计来抓把柄的机制，这比单纯否认偷商业秘密更有攻击性。
- **400 名员工流动**被写进诉状当证据，人才成为可量化的竞争指标。
- **诉讼本身就是竞争工具**：在硬件落地前用法院命令拖慢对手，比产品对撞更省钱。
- **需要保留的清醒**：双方各执一词、均为诉状单方陈述，法院已下令 OpenAI 停用相关机密；苹果的核心指控（盗用商业机密）尚未经审理，别把反诉当作事实认定。

### 9. 今天就能装／能改的工具链：MCP 补 8 个洞、llama.cpp 两连修、Gemini 16 行研究 Skill

11 月 27—28 日的开发者侧更新集中在「基础设施修补 + Agent 工具成熟」：

- **MCP v2.6.0**（版本 2026.11.27）修补 **8 个漏洞**，包括 mcp-server-git 允许 Git LFS 执行恶意程序、path 扩展泄漏环境变量、远程名称欺骗泄漏认证，Windows 上的 filesystem 服务器也有修复，用 MCP 搭 Agent 工具链的团队应立即升级。
- **llama.cpp 连续两修**：图执行逻辑改为直接从缓存读取递归状态、不再复制，本地推理 token 输出提速且修了 RWKV6/7、Vulkan、Metal 多后端兼容；另一修处理 CUDA NVFP4 MMQ 核心的 `y_scale` 越界读取，用 CUDA 12/13 跑低精度量化的用户应更新以避免算错或崩溃。
- **Google Gemini 开源 16 行研究 Skill**（DemoLab）：把开放式问题拆给多个子 Agent、各自限制操作次数、最后汇总引用报告，测试中拿到 **90% 以上**评分，支持 Antigravity、Claude Code、Cursor、Codex。
- **OpenGame**（Nexu-io 开源）：基于 MCP 的本地工具包，支持 **20+ Coding Agent** 生成 3D 与叙事游戏，Node.js **22.18+**、TypeScript、产出可编辑 HTML5 项目（含 Three.js），Apache 2.0。
- **CoT-Proxy**（论文）：从闭源前沿模型的动作与简短推理摘要蒸馏学生 Agent，在目标 action 前插空白 think 块填入 API 摘要、配 KL 散度惩罚限制漂移，解决闭源 API 隐藏完整思维链时的蒸馏困境。
- **Liquid AI d1.3-ultra** 在 Decision Index v2.1 排名第一（**76.4 分**），返回类型化输出与概率分布而非自由文本，适合高置信度自动化与不确定案例转人工。

**核心亮点：**
- **今天该排进更新清单的是 MCP 和 llama.cpp**：安全漏洞与越界读取直接影响生产，不是「看看就好」的新玩具。
- **Skill 化是 Agent 工程的新颗粒度**：16 行文本指令可版本控制、可复用，比写死在工作流里灵活得多。
- **决策模型的「概率分布输出」比自由文本更可用**：能路由、能转人工，脏数据和 OCR 错误场景才敢上自动化。
- **CoT-Proxy 对准真实痛点**：闭源 API 不给你完整思维链，蒸馏只能靠动作 + 摘要，这篇给了可执行路径。
- **需要保留的清醒**：Skill、OpenGame 仓库都很新，研究报告为厂商/论文自评，CoT-Proxy 尚未成为主流训练范式；先用测试账号和小任务评估，别直接进生产 CI。
